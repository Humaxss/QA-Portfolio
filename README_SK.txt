Vitajte v mojom QA Testing portfóliu

Volám sa Erik Mäsiar a momentálne rozvíjam svoje zručnosti v oblasti Software Quality Assurance (QA) so zameraním na manuálne testovanie a automatizované testovanie.

Dané portfólio prezentuje moje praktické skúsenosti s procesom zabezpečenia kvality softvéru – od návrhu manuálnych testovacích prípadov a reportovania chýb až po API testovanie, validáciu dát pomocou SQL a automatizované UI testovanie s využitím TypeScriptu a Playwrightu.

Projekty v tomto portfóliu na seba nadväzujú a spoločne demonštrujú kompletný QA proces – od manuálneho testovania a reportovania chýb až po API testovanie, validáciu dát pomocou SQL a automatizáciu testov.

Cieľom tohto portfólia je predstaviť praktické QA projekty pokrývajúce rôzne oblasti procesu testovania, vrátane:

Manuálne testovanie
API testovanie (Postman)
Validácia dát pomocou SQL
Reportovanie chýb (Jira)
Automatizované UI testovanie (TypeScript a Playwright)

Svoje portfólio neustále rozširujem osvojovaním si nových zručností, zdokonaľovaním svojich testovacích schopností a získavaním praktických skúseností v oblasti testovania softvéru.
