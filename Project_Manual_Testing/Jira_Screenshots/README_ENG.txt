Project Management - JIRA


This project demonstrates the use of Jira Software during the manual testing process. The project contains User Stories, Tasks, Bug Reports, Scrum Board and Backlog.


Test Environment:
OS: Windows 11
Project Management Tool: Jira Software
Methodology: Scrum

The purpose of this project is to demonstrate practical experience with:
Jira Software
Issue Management
User Stories
Tasks
Bug Reporting
Scrum workflow

Project Contents:

User Stories & Tasks
- The screenshot demonstrates issue organization, priorities, workflow status, assignees, and project management. Displays the complete Issue Management view in Jira, including User Stories and Tasks.

Bug Reports:
- Displays the list of Bug Reports created during my manual testing tests. Each bug includes information such as workflow status, reporter, priority and other issue details.

Scrum Board:
- Display the Jira Scrum Board used to manage testing activities.

Backlog:
- Displays the Jira Backlog used for sprint planning and prioritization of User Stories and Tasks before they are moved into an active sprint.
