This project demonstrates the use of SQL in the Manual Software Testing process. The purpose of the project is to verify and validate data stored in a database using SQL queries commonly performed during application testing.

Database Used: Chinook Database (SQLite)

Test Environment
OS: Windows 11
Database: SQLite
Tools:  DB Browser for SQLite
	Visual Studio Code
Tester: Erik Mäsiar

Project Contents:
SELECT
WHERE
LIKE
ORDER BY
Aggregate Functions (COUNT, AVG, MIN, MAX)
- Each SQL query includes a QA scenario describing the purpose of the data verification.
