Projekt má demonštruje využitie SQL v procese manuálneho testovania softvéru. Cieľom projektu je overovanie a validácia údajov uložených v databáze pomocou SQL dotazov, ktoré sa bežne používajú pri testovaní aplikácií.

Použitá databáza: Chinook Database (SQLite)

Testovacie prostredie:
Operačný systém: Windows 11
Databáza: SQLite
Nástroje: DB Browser for SQLite
	  Visual Studio Code
Tester: Erik Mäsiar

Obsah projektu:
SELECT
WHERE
LIKE
ORDER BY
Aggregate Functions (COUNT, AVG, MIN, MAX)
- Každý dotaz obsahuje QA scenár popisujúci účel overovania údajov.
