Practice Test Automation - Login Page Testing

This project is a continuation of my Manual QA Testing portfolio and demonstrates the transition from manual test execution to automated UI testing using Playwright and TypeScript. Each Playwright test corresponds to an existing manual test case using the same Test Case ID. Traceability between manual and automated testing.

Test Environment:
OS: Windows 11
Programming Language: TypeScript
Automation Framework: Playwright 
IDE: Visual Studio Code

Project Features:
- Page Object Model (POM)
- Automated Login testing
- Positive and Negative test scenarios
- Clear mapping between Manual and Automated Test Cases

Test Coverage:
- Successful login
- Invalid username
- Invalid password
- Empty username
- Empty password
- Empty username and password
- Boundary and validation scenarios

Traceability:
- Each automated Playwright test uses the same Test Case ID as the corresponding manual test.
Example:
TC_LP_001 -> Verify successful login
TC_LP_002 -> Verify login with invalid username
TC_LP_003 -> Verify login with invalid password
